## 📐 Mathematical Foundations

### 1. Stage 1: Arnold 2D Cat Map (Spatial Confusion)
The Cat Map is an area-preserving chaotic automorphism on the 2-torus $\mathbb{T}^2$:

$$\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 2 \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} \pmod N$$

Because $\det(A) = (1 \times 2) - (1 \times 1) = 1$, the matrix transformation is strictly invertible:

$$\begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} 2 & -1 \\ -1 & 1 \end{bmatrix} \begin{bmatrix} x' \\ y' \end{bmatrix} \pmod N$$

Iterating this automorphism shears and folds adjacent pixel coordinates across the canvas, rapidly collapsing adjacent spatial correlation from $r \approx 0.95$ down to $r \approx 0.40$.

### 2. Stage 2: Logistic Chaotic Map (Permutation Diffusion)
To eliminate residual spatial patterns, pixel values are permuted using an aperiodic chaotic trajectory generated by the non-linear recurrence relation:

$$x_{n+1} = r \cdot x_n \cdot (1 - x_n), \quad 3.57 \le r \le 4.0$$

In the chaotic regime with positive Lyapunov exponent ($\lambda > 0$), a continuous trajectory of length $N \times N$ is computed and sorted (`argsort`) to generate a unique pseudorandom index permutation vector.

## 🧠 Machine Learning Steganalysis Auditor

### Dataset Architecture
- **Total Samples:** 1,200 balanced image matrices (400 per security tier).
- **Security Classes:**
  - `Class 0: Plaintext` (Standard photographic images, textures, gradients)
  - `Class 1: Weak_Cipher` (Arnold Cat Map only — vulnerable to correlation attacks)
  - `Class 2: Strong_Chaos` (Arnold + Logistic Map — cryptographically robust)
- **12 Extracted Features:**
  - Shannon Information Entropy ($H$)
  - Chi-Square Uniformity ($p$-value)
  - GLCM Energy
  - Horizontal ($r_h$), Vertical ($r_v$), and Diagonal ($r_d$) Pixel Correlations
  - Horizontal ($\nabla_h$) and Vertical ($\nabla_v$) Sobel Gradient Magnitudes
  - Local $8\times8$ Tile Entropy Mean & Standard Deviation
  - Global Pixel Intensity Standard Deviation
  - Inter-Channel (RGB) Cross-Correlation

## 🚀 Quick Start Guide

### 1. Installation
Clone the repository and install all required Python dependencies:

```bash
git clone https://github.com/daksh151005/AetherCipher-AI-Security-Auditor.git
cd AetherCipher-AI-Security-Auditor
chmod +x install_requirements.sh run_app.sh
./install_requirements.sh
```

### 2. Launch the Web Dashboard
Start the application with automated browser launch:

```bash
./run_app.sh
```
Or run directly via Python:
```bash
python3 app.py
```
Open `http://127.0.0.1:5000` in your web browser.

### 3. Launch Standalone Desktop GUI
If you prefer a desktop application:
```bash
./run_app.sh --gui
```

### 4. Retrain / Evaluate the ML Model
To regenerate the dataset or retrain the 5 benchmark models from scratch:
```bash
python3 dataset_generator.py
python3 train_crypto_classifier.py
```

## 🔒 Security & Cryptanalysis Metrics

When an image is encrypted or decrypted, AetherCipher computes:
- **Adjacent Correlation ($r$):** Target is $r \approx 0.00$ (zero spatial correlation).
- **Shannon Information Entropy ($H$):** Target is $H \approx 8.000$ bits/symbol for an 8-bit channel.
- **Bitwise Reversibility:** Verified mathematically with Peak Signal-to-Noise Ratio ($PSNR = \infty\text{ dB}$).
- **AI Classification Verdict:** Live inference risk score identifying unencrypted plaintext, vulnerable scrambled ciphers, and full chaotic noise.
