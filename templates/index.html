How Chaos-Based Image Encryption Works

Natural images possess strong spatial correlation: adjacent pixels are nearly identical (rxy > 0.95). Classical block ciphers like ECB leave outlines visible. This system employs a two-stage chaotic dynamical cipher to achieve complete Shannon confusion and diffusion:

STAGE 1: ARNOLD 2D CAT MAP (SPATIAL SCRAMBLING) Confusion
x' = (x + y) mod N
y' = (x + 2y) mod N

Arnold's Cat Map is an area-preserving chaotic automorphism on the 2-torus. Because its matrix determinant is (1 × 2) - (1 × 1) = 1, it is strictly invertible and has a positive Lyapunov exponent, shearing adjacent pixel coordinates across the canvas until all spatial correlation collapses to near zero.

STAGE 2: LOGISTIC MAP (CHAOTIC PERMUTATION) Diffusion
xn+1 = r · xn · (1 - xn),   where 3.57 ≤ r ≤ 4.0

In the chaotic regime (3.57 ≤ r ≤ 4.0), the non-linear difference equation generates an aperiodic, non-repeating trajectory. An orbit of length N × N is generated and sorted (argsort) to produce a pseudo-random 1D index permutation vector, shuffling all pixel positions.

100% Lossless Decryption: Decryption applies the exact reverse operations in opposite order: Inverse Logistic Permutation followed by Inverse Arnold Cat Map, guaranteeing bit-for-bit mathematical identity (PSNR = ∞ dB, MSE = 0).
